# Frontend Implementation Tasks

This document tracks the Frontend specific tasks for the Sun Booking Tours project, categorized by priority and dependency.

- [ ] **FE-01** [FE] Setup Architecture, Shared Components, Landing & Auth

- [ ] **FE-02** [FE] Implement Tour Management

- [ ] **FE-03** [FE] Implement User Booking Management

- [ ] **FE-04** [FE] Implement Admin Booking Management
  - *Description*: Xây dựng giao diện và chức năng quản lý Booking dành cho Admin.
- [ ] **FE-09** [FE] Integrate Frontend with Backend APIs
  - *Description*: Tích hợp các chức năng Frontend với Backend APIs.
- [ ] **FE-10** [FE] Implement Authorization and Protected Routes
  - *Description*: Xây dựng phân quyền User/Admin và bảo vệ các route.
- [ ] **FE-11** [FE] Frontend Integration Testing
  - *Description*: Kiểm thử các chức năng và luồng chính của Frontend.
- [ ] **FE-12** [FE] Fix Frontend Integration Issues
  - *Description*: Xử lý lỗi và hoàn thiện Frontend sau quá trình tích hợp.
